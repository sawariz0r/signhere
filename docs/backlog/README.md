# Engineering backlog

Backlog documents describe proposed work. They do not change application behaviour or establish production readiness.

- [signhere.se central service](signhere-central/README.md): fifteen tasks covering privacy-first verification, independent timestamps, non-BankID approval, participant evidence, central operations and later capabilities.
- [Central-service architecture and delivery plan](../central-service-plan.md): scope, data boundaries, proposed flow and release sequence.

Each task records priority, owner role, dependencies, deliverables, acceptance criteria and verification evidence. Task status is maintained in its file.
